# Nuxt.js Project Design

## Pages

### Index Page

- This page is the landing page of the application.
- It includes a header with the title "Welcome to My Nuxt.js App".
- Below the header, there is a brief description of the app.
- The page also includes a button that navigates to the `/about` page.

## Components

### Header Component

- The header should display a title passed as a prop.
- The title is centered and styled with a large font size.
